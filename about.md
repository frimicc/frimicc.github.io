I am a Senior iOS Software Engineer with 10+ years of experience architecting,
designing, and scaling complex real-time mobile apps.

* I have a proven track record of
leading large-scale legacy codebase migrations (UIKit/Objective-C to
SwiftUI/Swift Concurrency) that drastically improve uptime and reduce customer
issues.
* I'm an early user of AI-assisted workflows—using modern toolchains (Claude Code,
Quality Layer, CodeRabbit) to aggressively accelerate delivery velocity, code
coverage, and system safety without compromising maintainability.
* I'm committed and tenacious, solving problems, fixing bugs, and always following through to
  make sure the users have a better experience. I own my code and care that it
  works well.
* I have an understanding of and history with
the full stack which lets me handle things like security, privacy, and performance
that often cause trouble for front-end or mobile-only developers.

## What I Do

* Write high-quality, maintainable, and testable code for a living
* with the help of modern LLMs and tools that help them make fewer mistakes.
* Design and architect complex real-time iOS apps and design REST back end services.
* Document processes, patterns, and decisions so that I only have to answer each question once.
* Communicate clearly and effectively, with both technical and non-technical
  audiences.
